# GlowRoutine — верстка вебсайту

Лабораторна робота № 3 «Верстка вебсайту засобами HTML і CSS».
Вебсайт б'юті-маркетплейсу та сервісу підбору доглядової косметики **GlowRoutine**.

Верстка виконана за інтерактивним прототипом і дизайн-системою з практичної роботи № 2 (Figma Make):
[GlowRoutine Website Prototype](https://www.figma.com/make/07YmZyefaN9qenlgjoj6de/GlowRoutine-Website-Prototype?t=uq0QCXGle0J1Ayni-1)

## Мета роботи

Сформувати практичні навички верстки адаптивного вебсайту відповідно до створеного прототипу з використанням семантичної розмітки HTML та засобів стилізації CSS.

## Що реалізовано

- семантична HTML-структура (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`);
- дизайн-токени з дизайн-системи (кольори, типографіка, форми й тіні) у вигляді CSS-змінних;
- макети сторінок на Flexbox і Grid;
- адаптивність через медіазапити (брейкпоінти 1100 px, 900 px і 760 px);
- шрифт Manrope (Google Fonts) і Georgia для акцентних заголовків.

## Організація CSS

Стилі розділені на три файли, які підключаються в такому порядку:

1. **`base.css`** — змінні `:root` (палітра, шрифти, радіуси, тіні), reset, базова типографіка, утиліти.
2. **`components.css`** — компоненти з дизайн-системи: навігація, кнопки, картки товарів, теги, форми тощо.
3. **`pages.css`** — розташування й особливості конкретних сторінок.

## Як запустити

Збірка не потрібна. Є два варіанти:

1. Завантажити або клонувати репозиторій і відкрити `index.html` у браузері.
2. Відкрити через локальний сервер, наприклад розширення **Live Server** у Visual Studio Code.

```bash
git clone https://github.com/xina-vii/glowroutine.git
cd glowroutine
```

## Адаптивність

| Пристрій | Ширина екрана |
| --- | --- |
| Десктоп | понад 1100 px |
| Планшет | 760–1100 px |
| Мобільний | до 760 px |

На мобільних пристроях макет перебудовується в одну колонку, навігація згортається в бургер-меню (реалізоване на чистому CSS через `checkbox` без JavaScript), кнопки розтягуються на всю ширину.

## Технології

HTML5 · CSS3 (Custom Properties, Flexbox, Grid, Media Queries) · Google Fonts (Manrope). JavaScript не використовується.
